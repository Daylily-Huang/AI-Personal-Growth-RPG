# 自定义任务进度增量

用户要求：将任务卡片固定 +25% 改为想增加多少就输入多少。

基线：PR64 / ed8e3472836e581ca9e080494f1ba5dd8e844b67。

本轮四个变更路径：本文件、src/components/quests/QuestCard.tsx、tests/quest-progress-custom.test.tsx、tests/helpers/monthly-scope.ts。

- 沿用原任务卡片，在原按钮位置输入任意有限正数百分比，支持小数、点击提交和回车。

- 后端、API、数据库、XP、Mastery、完成奖励、依赖及共享设计tokens不改；不对正式账号写入测试数据。
- 现有月度范围守卫只增加上面三个新增差异路径，保留完整范围、缺项、额外后端/迁移/依赖及漂移拒绝逻辑，不改旧测试主体。

验收：专属输入/边界/重复操作测试、原七状态与任务页测试、月度历史范围测试、类型/样式与生产构建；独立审查最终四路径候选后执行已有普通PR/CI交付流程。本机更新需要精确已验提交、构建与原有启动保护；临时环境按任务所有权清理。
