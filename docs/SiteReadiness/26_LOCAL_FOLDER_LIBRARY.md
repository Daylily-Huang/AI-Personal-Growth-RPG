# 本机资料文件夹与 AI 活动建议

日期：2026-10-16。基线：PR65 / 8fd9becf9e90242a43251d6bf628697de65295db。

用户授权：连接指定文件夹，读取学习笔记和作品，让 AI 整理活动与证据建议，用户确认后再记录。用户澄清：允许现有云端 AI 处理选中文件的必要内容；网站和原文件保留本机，不部署公网，原文件/配置/路径不提交 GitHub。

## 范围

- 浏览器原生文件夹选择；只读授权，可记住连接并重新授权、刷新、断开。无后台全盘扫描或文件修改。
- 文本笔记与代码作品：Markdown、TXT、R、Python、JS/TS、JSON/CSV、HTML/CSS、TeX。二进制/Office/PDF不冒充已解析；清楚列为不支持正文读取。
- 扫描不请求模型；显式勾选文件并确认发送后，才提交必要正文给当前已配置 AI。路径只含所选目录内相对名称，不上传原文件到 Storage/GitHub。
- AI只产出可编辑活动和待核实证据建议，原文引句必须逐字存在；不产生XP、Mastery、verified或作品认定。
- 记录必须明确确认。沿用现有 create_activity 和 rpc_submit_activity_evidence，提交证据固定E0/user_submission/verified=false。活动与证据分两步：证据失败保留活动编号、允许安全重试；不宣称原子事务。
- 本地持久回执、排他锁及同一来源版本去重；创建结果不明时拒绝自动重建并引导检查活动历史。浏览器保留待确认请求便于重试；服务重启后未保存草稿需要重新分析。
- API仅接受本机同源、真实认证用户、loopback数据库；不影响原有评估/确认/成长账本。
- README、CHANGELOG及当前进度更新，普通PR/CI同步代码；独立exact-head审查GO后才普通合并并更新本机入口。

## 不在范围

公网部署、改变现有AI供应商、本地模型安装、数据库迁移、读取整个电脑、自动监控/自动入账、把文件存在当作能力证明。

## 验收

读取边界/文件筛选/撤销连接；AI引用造假与提示注入边界；本机同源与认证隔离；确认前零业务写入；重复确认/部分失败重试；真实合成数据库与浏览器流程；build/lint/类型/全套测试与Growth Harness；源码及GitHub提交不含私人文件或密钥。独立验收最多首审+一次定向复验、总10分钟；只审上述三类安全命题，禁止嵌套。

## 精确新增授权范围

除本控制文档，仅允许本轮本地资料模块、专属API与页面、产出台入口、专属测试、README/CHANGELOG/交接与既有计划，以及旧月报范围守卫的显式增量清单。旧测试主体/历史冻结常量不改；新增路径必须完整列入范围清单，范围外变更仍拒绝。
