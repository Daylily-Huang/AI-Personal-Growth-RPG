# 本地资料：PPTX / DOCX 文字读取

日期：2026-10-17；基线 PR66 / 5037a69b9c0104032283a2f2b2c42991a441ceed。

用户反馈指定文件夹找到0文本/跳过2项，并确认文件为.pptx和.docx。本轮只补这两种格式的浏览器本地文字提取与明确错误提示；继续按26号授权，由用户勾选、同意云端AI处理后发送必要文字，核对确认后记录E0未验证证据。原文件、嵌入媒体不上传，扫描不请求AI，不执行正式数据库迁移。

读取范围：DOCX正文段落及表格中的文字（跳过删除修订）；PPTX按presentation实际顺序读取幻灯片文字及正文备注，保留页序标记，不按文件名猜顺序。不读取外部链接、嵌入对象、媒体；PDF、旧PPT/DOC、扫描件和图片OCR不在范围。Word页眉页脚、批注和脚注，以及图表/SmartArt中的独立数据部件暂不读取，不冒充视觉完整重现。

每文档上限20MiB，文本原有128,000字节限制保持；每批8份/64,000字符保持。只解压所需XML，每部件4MiB、累计12MiB，ZIP目录最多5,000项/演示500页；CRC/边界/压缩方法/加密/XML实体校验，不执行文档代码。超限、损坏或没有文字明确报错且整批不发送，不静默截断。来源哈希绑定实际提取并发送的UTF-8文字，不能作为原文件二进制完整性证明。

精确范围：本控制、office.ts及专属测试；已有schema/files/page、专属UI/边界/scope测试、旧monthly-scope显式新增3路径清单、README/CHANGELOG/MASTER及既有三计划。总16路径；不得修改API/AI/确认存储、数据库、XP/Mastery、依赖、其他页面或历史冻结正文。

验收命题：1本地解析、扫描零发送、勾选同意后仅提取文字发送；2读取顺序及来源哈希真实、错误不编造不截断；3确认/E0/认证/去重沿用已验原逻辑。相关测试、构建、真实浏览器格式夹具与明确错误；有界独审首审6调用、最多一次定向复验4调用、总10分钟、不嵌套。GO和CI后普通PR合并及原本机入口更新，无公网部署。

自检：146相关测试全过；type/lint/默认Turbopack生产构建通过。真实Chrome读取python-docx/python-pptx标准虚构文档、目录清单、选择同意、仅提取文字载荷与SHA256、损坏文档整批阻止、390px无溢出通过。浏览器本轮AI/认证接口为合成拦截，未调用真实云端AI、未确认保存、未写正式数据；既有真实AI及确认链路证据沿用PR66，不能冒称本轮重跑。系统原生选择器UI未自动化。独审/CI/合入/本机切换仍待。
