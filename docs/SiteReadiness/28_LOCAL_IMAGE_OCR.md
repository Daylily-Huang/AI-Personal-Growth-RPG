# 文件夹图片文字识别

日期2026-10-17；基线PR68 / 05c752c92025c8ea145cc4513a258e9a510a43e5。

用户要求：工作台文件夹中的图片文字也需要识别。沿用网站、原文件留本机、必要文字经明确同意才交给既有云端AI、确认后才记录活动及E0未验证材料的边界。

## 范围与流程

PNG/JPG/JPEG/WebP/BMP独立静态图片，每文件10MiB，最多8份/64,000字符保持。扫描只列清单。勾选图片→点击本机识别→浏览器核验图片头与4,000万像素上限、最长边缩小至2,600像素并白底转PNG→只发送本机同源已认证OCR接口→Windows自带OCR在内存中处理→显示图片预览和可编辑识别文字→另行明确同意云端AI处理文字→活动/证据建议→确认保存。

此机已只读探测Windows识别语言zh-Hans-CN。调用固定PowerShell脚本，无用户命令/URL/文件路径参数，图片从stdin进入内存，不落盘、不上传云端，不传递模型或数据库密钥。单个PNG栅格6MiB/2,600边长；请求8,400,000字节、结果64,000字符、子进程30秒超时及取消、同一进程一次识别，失败不调用替代云服务、不生成建议。非Windows/未启用本机识别语言明确报不可用。

识别结果可能漏字、混淆字母和数字、小数点与单位；只规范化中文词元间隔，不猜测修正数字，必须用户核对。改字会撤销AI同意；原图SHA256变化后禁止使用旧识别结果。来源版本哈希继续绑定实际发送的核对文字，不冒称原图完整性或能力证明。连接刷新/断开/账号变化清除当前内存预览；原有确认/E0/去重逻辑不改。

不包含：PDF、旧PPT/DOC、文档内嵌图片、SVG、GIF/动态图片、手写或复杂图表准确率保证、云端图片识别、新模型供应商、数据库/XP/Mastery变更或公网部署。
