# 任务优先的日常使用流程（2026-10-22）

用户问题：功能多，但不知道怎么用和先后顺序。用户选择：优先推进今天的目标和任务。

本轮是首页信息组织与导航改进，复用现有任务、记录、建议和复盘入口。主线：选一件任务 → 去现实行动 → 记录实际结果 → 核对成长建议 → 复盘并选下一步。真实行动环节不要求用户点击打卡，休息和暂停均可。

In Scope：首页常驻5步操作卡、按有无进行中任务提供入口、显示真实待核对建议数、空建议可访问落点、移动端先展示任务、记录文案通俗化；其他功能提供用途说明。
Out of Scope：任务优先级/今日计划算法、任务自动创建或激活、自动确认或发经验、AI模型/提示词、数据库、权限、奖励、原用户数据、全站导航重构。

数据表变更：无。服务端写入变更：无。沿用现有GET dashboard快照，不新增请求或持久存储。进行中任务仅由已有active状态判断，不宣称它们被排期到今天。待核对数只统计pending状态。流程按钮只导航、滚动与聚焦，实际写入仍依赖原表单和确认操作。

验收：新旧用户均看到主线；无任务时可直接设置目标且也可记录；暂停/归档/完成任务不冒充进行中；只统计pending建议；记录按钮聚焦原输入且保留草稿；核对按钮能到空/非空建议区；所有链接到现有路由；支持44px触控与键盘、不强制流程；移动端/长中文无溢出；既有活动提交/确认处理函数保持不变。
